Host Security

IPDS Pro

A Python-based Intrusion Prevention & Detection System for real-time network traffic inspection, multi-stage threat detection, risk scoring, and automated containment. Built with Scapy, PyQt6, SQLite, MaxMind GeoLite2, OS firewall controls, and Suricata EVE JSONL logging. It inspects Layer 3/4/7 traffic, detects threats including SQL injection, command injection, XSS, path traversal, DoS, and brute-force activity, correlates per-IP risk, and supports temporary or persistent firewall blocking. GeoIP/ASN intelligence and SIEM-friendly logs support investigation and observability.

AI + Cybersecurity

AI IPDS

An AI-assisted Intrusion Prevention & Detection System combining network packet analysis and deep packet inspection with deep-learning-based anomaly detection. The project stack includes Python, Scapy, BPF, PyTorch, NumPy, CNN/LSTM/VAE models, and AMD ROCm/HIP, with Linux iptables/conntrack/tc and Windows netsh firewall controls. Supporting components include Suricata EVE-JSONL logging, PyQt6/QtWebEngine, Flask REST APIs, WebSockets, SQLite3 (WAL mode), MaxMind GeoIP2/ASN intelligence, IOC tracking, MITRE ATT&CK mapping, incident-response playbooks, Claude API integration, system/GPU monitoring, and PDF report generation.
